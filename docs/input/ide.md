# Ide: KosFinder

**Pengguna:**
- Mahasiswa atau masyarakat yang mencari kos di sekitar kampus (tidak perlu login untuk melihat daftar).
- Pemilik kos yang ingin mempublikasikan kosnya (perlu login).

**Masalah:**
Informasi kos saat ini tersebar di media sosial dan grup WhatsApp. Pencari kos kesulitan membandingkan harga, fasilitas, dan lokasi. Pemilik kos juga kesulitan memperbarui ketersediaan kamar secara real-time.

**Yang diharapkan bisa dilakukan:**
- Pencari kos dapat melihat daftar kos, mencari berdasarkan nama/area, menyaring berdasarkan harga, dan melihat detail kos.
- Pemilik kos dapat mendaftar, login, menambah kos baru, serta mengubah dan menghapus kos MILIKNYA SENDIRI.

**Batasan (Scope):**
- Aplikasi berbasis Android, dibangun dengan Flutter. Backend menggunakan Supabase.
- Versi pertama TIDAK mencakup: pembayaran online, fitur chat, ulasan/rating, rekomendasi AI, verifikasi identitas pemilik, upload foto asli, dan peta lokasi.
